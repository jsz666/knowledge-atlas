# 07 《知识星图》——文档关系探索器

把一堆论文、Markdown 笔记和课程讲义变成一张可以沿着关系探索的知识星图。

## 核心闭环

```
文档上传 → 解析分块 → AI 抽取实体/关系(带来源)
        → 人工确认修正 → 图可视化探索 → 跨文档证据问答
```

- **AI 负责**:实体关系抽取、问题中关键概念识别、跨文档总结
- **程序负责**:图遍历(BFS)、来源追踪、证据组织、去重与校验

## 功能一览

| 能力 | 说明 |
|---|---|
| 图谱交互 | 类型 / 状态筛选、5 种布局切换、缩放与适应窗口、悬停 tooltip、双击展开邻居(大图模式)、**跨文档实体紫色描边** |
| 最短路径 | 任选两个实体查最短关系路径,并在星图上高亮整条路径 |
| 新增与编辑 | 图谱上「+ 实体」建节点;节点详情里新增 / 编辑描述 / 删除关系 |
| 撤销 / 重做 | 删除前自动存快照,支持单步、跳序(点某一条)、批量勾选撤销,以及按序重做 |
| 导出 | 完整 JSON 快照(含原文片段) / CSV 实体或关系清单 / Markdown 关系清单(附证据) |
| 导入 | 上传 JSON 快照合并回图谱,**幂等**(重复导入不产生重复数据) |
| 实体消歧 | 归一化识别重复实体(忽略大小写、空格、标点与"模型/方法"等后缀)并合并,关系与证据自动迁移 |
| 统计概览 | 顶部显示文档 / 实体 / 关系 / 跨文档实体 / 待确认数量 |
| 问答历史 | 历史提问可回看,含关键概念、关系路径与原文证据 |
| 文档片段 | 侧栏可展开查看任意文档的原文片段,便于从证据回看上下文 |
| 示例数据 | 右上角「载入示例」一键灌入 4 篇文档 / 16 实体 / 18 关系,**无需密钥** |

## 环境准备

> 验收要求:项目须能在 **WSL** 中独立启动并完成主要功能,建议开发期就直接在 WSL 内操作。

### WSL 首次准备(推荐)

代码请放在 WSL 文件系统内(例如 `~/knowledge-atlas`),**不要放在 `/mnt/c/...`**:
WSL 跨文件系统访问 Windows 盘时,npm 安装与 SQLite 读写都会非常慢。

首次在 WSL 内执行一次(需要 sudo 密码):

```bash
sudo apt update
sudo apt install -y python3-pip python3-venv nodejs npm
```

`start.sh` 自带环境自检:pip 缺失时会尝试装到用户目录,Node 缺失时会回退复用 Windows 侧的 Node。
但**原生安装最稳妥**,自检只是兜底。

```bash
# 1. 后端
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # 填入自己的模型密钥(可留空)

# 2. 前端
cd ../frontend
npm install

# 3. 一键启动(仓库根目录,需要两个终端或后台运行)
./start.sh
```

启动后:前端 http://localhost:5173 ,后端接口文档 http://localhost:8000/docs

> 关闭启动终端会连带停掉服务。若希望终端关闭后仍保持运行,可用
> `setsid nohup npm run dev -- --host 0.0.0.0 --port 5173 &` 启动前端。

## 配置说明(`backend/.env`)

| 变量 | 必填 | 说明 |
|---|---|---|
| `OPENAI_API_KEY` | 否 | 留空则进入**离线兜底模式**,链路仍可跑通 |
| `OPENAI_BASE_URL` | 否 | OpenAI 兼容端点,可换成 DeepSeek / 通义等 |
| `OPENAI_MODEL` | 否 | 默认 `gpt-4o-mini` |
| `MAX_CHUNKS_PER_DOC` | 否 | 单文档最多抽取的块数,默认 40 |

**密钥只存在于后端 `.env`,不会写入前端,也不会提交到仓库。**

## 无密钥也能跑

未配置 `OPENAI_API_KEY` 时,抽取环节会自动降级为**规则启发式**(大写缩写词/术语共现),
问答环节返回程序生成的"证据清单式"答案,并在响应中标注 `model_available: false`。

想直接看效果:启动后点右上角 **「载入示例」**,即可灌入一份围绕
Transformer / RAG / 知识图谱 / BERT 的示例星图(16 个实体、18 条关系,含跨文档实体),
所有界面功能都能试,不需要任何密钥。

## 数据库表

| 表 | 作用 |
|---|---|
| `documents` | 上传文档元信息与抽取状态 |
| `chunks` | 文档分块,证据定位的最小单位 |
| `entities` | 实体节点,带 `status`(pending / confirmed / rejected)与 `mention_count`(热度) |
| `relations` | 实体间关系边,同样带 `status` |
| `evidence` | 实体/关系 → 原文片段的来源追踪 |
| `entity_aliases` | 实体别名:消歧合并后被并掉的旧名字,保证用旧名仍可搜索、可追溯 |
| `qa_records` | 问答历史与证据快照 |
| `trash` | 删除快照栈(`stack` 区分 undo / redo),支撑撤销与重做 |

完整性约定:

- **级联删除**:删文档会连带删除它的片段与证据,删实体会连带删除挂在它身上的关系、
  证据与别名,不留孤儿数据(依赖 SQLite 的 `PRAGMA foreign_keys=ON`,连接建立时自动开启)。
- **并发写入**:启用 WAL 与 `busy_timeout`,读写互不阻塞,并发写不再直接报 `database is locked`。
- **实体热度**:`mention_count` 冗余保存该实体的证据条数,抽取 / 合并 / 删除 / 撤销后自动重算。
- **平滑升级**:`create_all` 不会改已存在的表,因此启动时自动 `ALTER TABLE` 补齐新列并建索引;
  若发现历史库的热度从未计算过,会自动补算一次。

## 导出与导入

- 右上角 **导出 ▾** 可选:JSON 完整快照 / CSV 实体 / CSV 关系 / Markdown 关系清单。
- 右上角 **导入** 选择导出的 JSON 文件即可合并回图谱。
- 导入采用**合并策略**(文档按标题、实体按 name+type、关系按三元组匹配),重复导入不会产生重复数据。
- 实体合并(消歧)不可撤销,建议操作前先导出一次快照备份。

## 账号与数据隔离

- **注册 / 登录**:右上角「登录 / 注册」,用户名 + 密码(口令至少 6 位)。密码用
  PBKDF2 加盐哈希存储,不保存明文;登录成功后签发签名令牌,存于浏览器本地,刷新免登录。
- **完全隔离**:文档、实体、关系、证据、问答、撤销记录都归属各自账号,
  账号之间互不可见,也不能修改或删除对方的数据。
- **匿名只读**:不登录可以打开页面,但只能看到无主的公共数据;上传、确认、删除、
  合并、撤销、问答落库等写操作会返回 401 并提示登录。
- **历史数据不丢**:引入账号之前就存在的无主数据,由**第一个注册的用户**接管,
  不会变成谁都看不到的孤儿数据。
- 内置演示账号:`demo` / `demo12345`(已灌好示例星图),也可以自行注册新账号。

## 界面与体验

- **统一提示**:操作结果用右下角 Toast 呈现(不再弹系统 `alert`);危险操作改用样式一致的
  确认弹窗,并说明影响范围(例如删除文档会连带清理它的片段与证据)。
- **加载与空状态**:首屏显示骨架屏而不是空白;首次进入且没有任何数据时给出引导,可一键载入示例。
- **键盘快捷键**:`Ctrl/⌘ + Z` 撤销、`Ctrl/⌘ + Shift + Z` 重做、`/` 聚焦搜索、`Esc` 收起浮层。
- **即时搜索**:输入后自动防抖搜索(回车立即搜并跳到结果页),支持用合并前的旧名字搜索。
- **拖拽上传**:文档面板支持把 PDF / Markdown / TXT 直接拖入上传。

## 演示链路

1. 点「载入示例」或上传 5~10 篇同主题文档(PDF / Markdown / TXT)
2. 在「人工确认」里修正一两条抽取错的实体或关系;有重复实体可用「实体消歧」合并
3. 在星图上筛选类型、切换布局、缩放、悬停看详情、双击展开邻居;用「查路径」看两点如何连通
4. 提出跨文档问题,查看答案 + 关系路径 + 原文证据;在「问答历史」里回看
5. 用「导出 ▾」导出 JSON / CSV / Markdown,再用「导入」验证闭环
6. 打开 `data/knowledge_atlas.db` 展示真实落库记录

## 常见问题

- **Windows 本机开发、WSL 验收**:确保 `data/` 与依赖都在 WSL 文件系统内,不要用 `/mnt/c` 路径,否则 SQLite 与文件锁容易出问题。
- **端口占用**:改 `start.sh` 里的 `UVICORN_PORT` / `VITE_PORT`。
- **PDF 抽不出文字**:扫描版 PDF 需要 OCR,基础版暂不包含,可先转成 TXT/Markdown。
- **抽取很慢**:调小 `.env` 里的 `MAX_CHUNKS_PER_DOC`。
- **重启后表结构报错**:新增字段(如 `trash.stack`)不会自动迁移旧库,删掉 `data/` 目录让表重建即可。
- **图谱节点很多**:超过 80 个节点会自动进入大图模式,只渲染核心节点,双击可展开邻居,也可在「视图」里切换为显示全部。
